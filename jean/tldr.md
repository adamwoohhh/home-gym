# 健身计划速查

## 通用热身

1. 脚趾抓地和放松：30 秒。
2. 短足训练：每侧 8-10 次。
3. 脚趾瑜伽：每侧 8-10 次。
4. 弹力带蚌式开合：2 组 x 12 次。
5. 徒手半蹲对线：2 组 x 8 次。

如果当天已经做 A 类足踝视频，热身可缩短到 3 分钟。

## 临时替换

| 情况 | 怎么换 |
| --- | --- |
| 膝盖不舒服 | 跳过快速深蹲、箭步蹲，改臀桥、死虫、鸟狗 |
| 小腿紧 | 减少站立有氧，周三改轻阻力单车 |
| 心率太高 | 视频只做前 12-15 分钟，或换 E1 低强度做 |
| 时间不够 | 足踝选 A3，背部选 B3，核心选 C2 或 C3 |
