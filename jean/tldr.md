# 健身计划速查

## 通用热身

| 场景 | 做什么 |
| --- | --- |
| 默认 | A1 全程 |
| 足弓状态差、小腿紧 | A2 前 6-8 分钟 |
| 时间很紧 | A3 全程 |
| 需要臀中肌激活 | G2 前 3-5 分钟 |

如果当天计划里已经有 A1/A2/A3/G2，不用额外重复热身。

## 临时替换

| 情况 | 怎么换 |
| --- | --- |
| 膝盖不舒服 | 跳过快速深蹲、箭步蹲，改臀桥、死虫、鸟狗 |
| 小腿紧 | 减少站立有氧，周三改轻阻力单车 |
| 心率太高 | 视频只做前 12-15 分钟，或换 E1 低强度做 |
| 时间不够 | 足踝选 A3，背部选 B3，核心选 C2 或 C3 |
