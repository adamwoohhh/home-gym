# 基础条件

- 性别: 女
- 身高: 160cm
- 体重: 61kg
- 劣势: 扁平足（小腿粗、膝盖弯）、气血不足（难以坚持长时间高心率运动）

# 目标

- 周期： 16周
- 目标体重： 50kg

## 阶段一

- 改善扁平足，调整腿部力线
- 建立运动习惯
- 轻度减脂，体重: 61kg -> 58kg

## 阶段二

- 重点减脂，体重: 58kg -> 55kg

## 阶段三

- 减脂，体重: 55kg -> 53kg
- 塑型，构建线条，重点背部和腹部

## 阶段四

- 减脂巩固，体重: 53kg -> 50kg

# 要求

- 扁平足导致的小腿力线问题比较突出，调整扁平足问题需要贯穿全阶段计划。
- 前期在扁平足问题改善前，需要减少跑跳型运动。
- 避免长时间高心率运动。
- 单次运动时长小于40min。
- 每周4天运动。
